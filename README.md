# MIA Assistant 2.2

MIA — настольный ИИ-ассистент для Windows в духе Джарвиса. Приложение написано
на Python и PySide6 и объединяет обычный чат, инструменты разработчика, поиск,
GitHub и локальные голосовые функции.

## Что умеет MIA

- автоматически выбирает прямой DeepSeek, OpenRouter или локальную Qwen и показывает ответ по мере генерации;
- помнит контекст текущего диалога и восстанавливает его после перезапуска;
- загружает актуальный список моделей OpenRouter прямо в интерфейсе;
- останавливает генерацию, копирует последний ответ и экспортирует разговор в Markdown;
- озвучивает ответы системным голосом Windows;
- работает как голосовой ассистент: локально ждёт обращение «Мия», принимает команду и отвечает голосом;
- показывает прогресс этапов: запись, распознавание, исправление, выбор нейросети, ответ и озвучивание;
- при установленных голосовых зависимостях распознаёт шестисекундную диктовку локальным Whisper;
- ищет информацию через DuckDuckGo и извлекает основной текст страницы;
- объясняет и проверяет код, составляет ТЗ и планы разработки;
- помогает создать GitHub-репозиторий, предварительно проверив проект на секреты;
- содержит справочник по методологиям и правилам оформления проекта.

## Быстрый запуск на Windows

1. Установи Python 3.10 или новее.
2. Запусти `setup.ps1` из PowerShell:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1 -WithVoice -WithLocalAI
   ```

3. Этот шаг необязателен: чтобы использовать облако, открой созданный локальный
   файл `.env` и вставь **один** свежий ключ DeepSeek или OpenRouter:

   ```dotenv
   OPENROUTER_API_KEY=твой_ключ_если_выбран_OpenRouter
   OPENROUTER_MODEL=deepseek/deepseek-chat
   DEEPSEEK_API_KEY=твой_ключ_если_выбран_DeepSeek
   DEEPSEEK_MODEL=deepseek-v4-flash
   ```

4. Запусти `autorun.bat` двойным кликом. Если голосовых компонентов ещё нет,
   файл сам установит их и скачает русскую офлайн-модель.

Необязательный ключ можно передать установщику сразу, не редактируя файл вручную:

```powershell
.\setup.ps1 -OpenRouterKey "твой_ключ" -Launch
```

`.env` никогда не отправляется в GitHub.

## Нейросети и автоматический резерв

По умолчанию MIA проверяет провайдеров в порядке `DeepSeek → OpenRouter → local → Ollama`.
Если ключ отклонён или облако недоступно до начала ответа, запрос автоматически переходит
к следующему варианту. Прямой DeepSeek использует официальный адрес `api.deepseek.com`.

`-WithLocalAI` устанавливает CPU-движок `llama.cpp` и официальную Qwen2.5 3B Instruct
в формате Q4_K_M (около 2 ГБ). Локальная модель работает без аккаунта, ключа и интернета.
Ключи Google, Яндекса, DeepSeek и других облаков нельзя создать программно без аккаунта
владельца и, при необходимости, подключённого биллинга.

## Полноценный голосовой режим

Установи голосовые зависимости и официальную русскую модель Vosk одной командой:

```powershell
.\setup.ps1 -WithVoice
```

После этого открой MIA и нажми `Голосовой режим: ВЫКЛ`. Когда кнопка станет
зелёной:

1. Скажи «Мия» и дождись звукового сигнала, затем произнеси команду.
2. Либо произнеси всё сразу: «Мия, составь план на день».
3. MIA отправит распознанную команду в выбранную LLM, озвучит ответ русским
   голосом Windows и снова начнёт ждать слово «Мия».

Слово активации распознаётся локальной русской моделью `vosk-model-small-ru-0.22`,
а сама команда повторно обрабатывается более точной `Whisper large-v3-turbo` и
контекстным корректором наподобие T9. Микрофон включается только после явного нажатия
кнопки голосового режима; звук никуда не сохраняется и не отправляется.

Отдельная кнопка `Диктовать 6 сек` использует ту же Whisper `large-v3-turbo` с
принудительно выбранным русским языком. При первом использовании Whisper может
скачать модель в локальную папку `models`. Вся папка `models` исключена из Git.

Модель Vosk скачивается из [официального каталога Alpha Cephei](https://alphacephei.com/vosk/models)
и распространяется по лицензии Apache 2.0. Для озвучивания MIA выбирает русский
голос Microsoft Irina, если он установлен, иначе использует доступный системный голос.

## Разработка и проверка

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Собрать переносимую Windows-версию:

```powershell
.\build.ps1
```

Результат появится в `dist\MIA-Dev-Agent`.

В сборке уже лежат локальные Qwen, Whisper и Vosk, поэтому облачный ключ для запуска
не нужен. Если захочешь подключить облако, скопируй `dist\MIA-Dev-Agent\.env.example`
в `.env` в той же папке и добавь один свежий ключ. Секретный `.env` не включается в сборку.

## Структура

- `mia_dev_agent.py` — Qt-интерфейс и вкладки приложения;
- `mia_core.py` — облачные и локальные ИИ-провайдеры, резервирование и память;
- `ui/` — оригинальная эмблема MIA и тема интерфейса;
- `tests/` — тесты ядра;
- `GITHUB_GUIDE.md` — отдельная русская памятка по работе с GitHub;
- `CHANGELOG.md` — список заметных изменений.

История чата хранится локально в `memory/chat_history.json`. Ключи, история,
логи, модели, виртуальное окружение и личные документы не публикуются.

## Памятка по GitHub

Если Git пока незнаком, начни с [GITHUB_GUIDE.md](GITHUB_GUIDE.md): там есть
короткий безопасный порядок `status → add → commit → push` и объяснение основных
команд без лишней теории.
