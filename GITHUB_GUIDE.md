# Памятка по GitHub для проекта MIA

Открытый репозиторий проекта:
<https://github.com/Himera2134567/mia_assistant>

## Что где находится

- Папка проекта на компьютере — это локальный репозиторий.
- Страница проекта на GitHub — удалённый репозиторий.
- `main` — основная ветка с рабочей версией проекта.
- Коммит — сохранённая контрольная точка изменений.

## Как отправить новые изменения

Открой PowerShell в папке проекта и выполни:

```powershell
git status
git add .
git commit -m "Кратко опиши изменение"
git push
```

Перед `git add .` полезно выполнить `git status` и проверить список файлов.
Файл `.env` с ключами, папки `.venv`, `models`, `logs` и `memory` отправляться
не должны — они уже перечислены в `.gitignore`.

## Как скачать изменения с GitHub

```powershell
git pull
```

Сначала сохрани или закоммить свои незавершённые изменения, иначе Git может
сообщить о конфликте.

Если проекта ещё нет на другом компьютере, его можно скачать один раз командой:

```powershell
git clone https://github.com/Himera2134567/mia_assistant.git
cd mia_assistant
```

После этого для обновлений достаточно `git pull`.

## Как посмотреть контрольные точки

Посмотреть историю:

```powershell
git log --oneline --decorate -10
```

Посмотреть изменения после последнего коммита:

```powershell
git diff
```

Не используй `git reset --hard`, если не уверен: эта команда может удалить
незакоммиченные изменения.

## Важное правило безопасности

Никогда не публикуй API-ключи и токены. Если ключ случайно попал в коммит,
одного удаления строки недостаточно: ключ нужно сразу отозвать у провайдера и
выпустить новый.

## Полезный рабочий порядок

1. Выполни `git pull`.
2. Внеси небольшое законченное изменение.
3. Проверь приложение.
4. Выполни `git status` и `git diff`.
5. Создай коммит с понятным названием.
6. Выполни `git push`.

Так историю проекта легче читать, а неудачное изменение — находить и исправлять.
