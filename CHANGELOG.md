# История изменений

## 2.1.0

- Добавлен непрерывный голосовой режим с локальной активацией словом «Мия».
- Команду можно произнести вместе со словом активации или после звукового сигнала.
- После ответа MIA говорит русским системным голосом и автоматически возобновляет прослушивание.
- Добавлена актуальная русская модель `vosk-model-small-ru-0.22` и безопасный загрузчик с официального сайта.
- Исправлена работа Vosk из Windows-путей с кириллицей через короткий нативный путь.
- Диктовка Whisper теперь явно распознаёт русский язык.
- Голосовая модель автоматически включается в переносимую Windows-сборку.

## 2.0.1

- В папку Windows-сборки автоматически добавляется безопасный `.env.example`.
- В README уточнена настройка OpenRouter для переносимого `.exe`.

## 2.0.0

- Потоковые ответы OpenRouter без зависания интерфейса.
- Полноценный контекст диалога и локальная память между запусками.
- Загрузка актуального списка моделей OpenRouter.
- Остановка генерации, новый диалог, копирование и экспорт ответа.
- Озвучивание ответов системным голосом Windows.
- Необязательная локальная диктовка через faster-whisper.
- Новый тёмный интерфейс и понятные статусы подключения.
- Оригинальная футуристичная эмблема MIA вместо фото-аватара.
- Безопасные GitHub remote URL: токен больше не сохраняется в `.git/config`.
- Секреты маскируются в отчёте встроенного сканера.
- Исправлены установка, запуск и переносимая PyInstaller-сборка.
- Добавлены тесты независимого от интерфейса ядра.

## 1.0.0

- Первый публичный снимок исходного проекта MIA.
